# Test Skill

This is a test skill to verify that the skill loading mechanism is working correctly in OpenDora.

## Purpose

This skill demonstrates:
- Skill discovery and loading
- Skill metadata parsing
- Skill content delivery to agents

## Usage

When an agent loads this skill, they should receive these instructions and be able to confirm that the skill system is operational.

## Test Instructions

If you can read this, the skill system is working! You should:
1. Confirm you can see this content
2. Report the skill name and description
