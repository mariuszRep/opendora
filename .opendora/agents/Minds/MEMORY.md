Rule: For ecosystem-governance changes, first load the relevant local ops skill (agent-ops, skill-ops, or tool-meta-ops) before considering delegation.

**Why:** Missing skill load can create false tooling gaps and unnecessary delegation.

**How to apply:** Do a quick skill-fit check, load the matching ops skill, verify tools are available, then execute locally. Delegate only if a real blocker remains after that.
