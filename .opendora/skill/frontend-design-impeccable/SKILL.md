# Frontend Design + Impeccable Discipline

Use this skill when a request involves frontend design/build quality and execution must remain tightly controlled.

## Objective

- Produce distinctive, production-grade frontend design outcomes.
- Enforce disciplined execution with explicit ownership, tool-path, and delegation checks.

## Frontend Design Standard

1. Prioritize clear visual direction over generic templates.
2. Use purposeful typography, color system, spacing rhythm, and responsive behavior.
3. Ensure accessibility, state coverage, and implementation realism.
4. Avoid bland AI-default UI patterns unless explicitly requested.
5. Preserve existing design systems when working inside established products.

## Execution discipline

- Re-verify ownership, skill options, and tool path before major decisions.
- Perform broad skill scan each turn; if any available skill has credible upside, load it.
- Keep execution local for ecosystem-owned artifacts.
- Delegate only when outside scope, authority/tools unavailable locally, or proven local blocker.
- Do not delegate by habit or speed.
- When blocked, state exact blocker and why local resolution is not possible.

## Delegation Specialist

When desktop GUI automation through PyAutoGUI is needed, delegate to PyAutoGUI Agent if the runtime delegate schema exposes it as an available target.

If assignment is blocked by permissions or missing tooling, return exact blocker and minimal next action.

## Rules

- Keep outputs concise, testable, and implementation-ready.
- Do not claim checks that were not executed.
- Prefer reversible, low-risk edits and explicit verification steps.
