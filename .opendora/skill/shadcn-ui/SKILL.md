# shadcn/ui

Use this skill when tasks involve shadcn/ui components or design-token-consistent UI changes.

## Scope
- Component composition and variant use
- Tailwind class hygiene and token alignment
- Form, dialog, table, and command-style primitives

## Workflow
1. Locate existing component usage patterns.
2. Reuse established primitives before adding new ones.
3. Keep classes readable and variant-driven.
4. Verify responsive behavior and accessibility basics.

## Rules
- Prefer composition over one-off bespoke markup.
- Maintain consistency with existing theme tokens.
- Avoid introducing unused abstractions.
