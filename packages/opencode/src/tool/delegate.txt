Use this tool to delegate work to another agent session.

It can:
- send a prompt to an existing session
- create a new session for a target agent and send the prompt there
- optionally wait for the delegated agent's reply, or just post the message and continue

Use this when you need broader delegation than the task tool:
- target a primary agent such as build or plan
- message a specific existing session by session id
- create a fresh delegated session without forcing the subagent task workflow

When creating a new session, provide an agent.
When messaging an existing session, provide either the session id alone, or the session id plus an agent override.
