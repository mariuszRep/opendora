Use this tool whenever you need direct input from the human user — regardless of whether
you are in a delegated session or not. question is the only tool that opens a direct
channel to the user for live dialogue.

Use question for:
1. Gathering user preferences or requirements
2. Clarifying ambiguous instructions
3. Getting decisions on implementation choices
4. Offering choices about direction

This applies even when you are in a delegated session with a reply_to contract. If you
need the user's answer to proceed, use question — not reply. reply cannot carry the
user's response back to you; question can.

Usage notes:
- When `custom` is enabled (default), a "Type your own answer" option is added automatically; don't include "Other" or catch-all options
- Answers are returned as arrays of labels; set `multiple: true` to allow selecting more than one
- If you recommend a specific option, make that the first option in the list and add "(Recommended)" at the end of the label
