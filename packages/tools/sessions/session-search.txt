Search and fetch sessions in OpenDora. This tool allows agents to find existing sessions and retrieve their details, enabling session switching and management.

Use this tool to:
- Find sessions by title, type, status, or agent
- Get specific session details by ID
- List root sessions or filter by directory
- Search for sessions to switch context
- Find only sessions owned by the current agent (owned_only: true)

Title search supports glob patterns (similar to the Glob tool):
- Plain term: "auth" — case-insensitive substring match
- Wildcard: "*login*" — matches any title containing "login"
- Prefix: "feature*" — matches titles starting with "feature"
- Single char: "fix-issue-?" — matches with any single-character wildcard

Ownership filtering:
- owned_only: true — restricts results to sessions belonging to the calling agent (resolved by agent storage ID, not display name)
- owned_only: false (default) — returns sessions across all agents
- agent_id — filter by a specific agent ID (mutually exclusive with owned_only)

Session markers in results:
- is_current_session: true — this session is the one this tool was called from (self-reference)
- is_owned_by_searcher: true — this session belongs to the calling agent (present on all matching results, not only when owned_only is set)

Exclusion:
- exclude_session_id — a single session ID or array of IDs to exclude from results; useful for removing the current session from candidate lists without suppressing is_current_session on other lookups

The tool supports various filters and can return detailed session information including metadata, message counts, and timestamps.
