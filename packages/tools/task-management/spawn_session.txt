Use this tool to create a delegated session and immediately ping it.

It can create:
- a child `worker` session under the current session
- a new root session, typically a `role` session

Use this when the work should live in its own session instead of another agent's main thread.

The `agent` parameter must be an agent ID exactly as listed in the Task tool's available agent types. Do not invent or guess agent names — only use IDs that appear in that list.
